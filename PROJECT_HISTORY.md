# Project History

The project was built incrementally with small, reviewable commits.

## Evolution

1. Initial project documentation
2. Python project setup
3. DBF reader and schema inspection
4. CSV and JSON export support
5. Configurable data validation
6. Configuration, logging, and CLI
7. Synthetic sample data and modernization notes
8. Unit tests

- Add REST API wrapper
- Add schema-diff reporting
